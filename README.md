# JihaMatch (지하매치)

> 한국인 개인의 **맞춤형 거주지 이전 계획 에이전트**
> "매물이나 정책을 직접 찾아볼 필요 없이, 나에게 유리한 기회가 생기면 알려준다"

---

## 한 줄 정의

사용자가 **한 번만 자신의 조건을 입력**하면, 시스템이 실시간으로
① 살 수 있는 곳 ② 얼마까지 가능한가 ③ 어떤 지원·감면이 붙는가 를 계산하고,
기회 상태가 **변하는 순간에만** 알린다.

## 왜 이게 지금 가능한가 (그리고 아무도 안 하는 이유)

시장 조사 결과, 매물 큐레이션은 이미 포화 상태다.

| 서비스 | 2026-11 시점 기능 | 선점된 축 |
|---|---|---|
| 직방 | AI중개사(MCP·ChatGPT 연동), **청약진단 리포트 12개 유형**, **지킴진단** | 청약 판정 + 계약 전 진단 |
| 호갱노노 | 검색필터·안심알리미, **청약 진단**, 전국분양정보(공공·민간) | 공급 파이프라인 |
| 네이버부동산 | **AI탭 1,000만 명**, 8월 매물찾기 에이전트, 네이버페이 상담 연결 구상 | 결제 + 에이전트 |
| 다방 | AI방찾기, AI 동네이야기, **안심진단**, AI 권리분석 | 대화형 탐색 + 사기 판별 |
| KB부동산 | AI 매물검색·단지분석, 내집내집, **찾아줘 내집**(256만 매물) | 금융 결합 |
| 집값박사 (zipgab-doctor) | 내집마련 후보 비교·시세추적·자산관리 | **직접 경쟁** |

**"AI로 매물 추천"은 더 이상 차별점이 아니다.** 그리고 그 방식을 따라가면
막힌다 — 2026년 1월 4일 특허법원 판결이 그 벽을 선명하게 그었다.

> **네이버 v. 다윈프로퍼티 (특허법원, 2026. 1. 4. 2심)**
> 네이버가 2심에서도 승소. 매물 DB 복제·전송 금지, **8,000만 원 배상**,
> 서버 저장된 24개 항목 데이터 **삭제 명령**.
> 재판부는 "약 10억원을 투입해 확인매물 시스템을 구축·유지했다",
> "원본 자료를 직접 생성하지 않았더라도 정렬·가공하면 DB 제작자"라고 인정.


## 2026-11 시장 조사: 남은 빈틈

> 전체 조사 보고서(81개 출처): [한국 부동산 정보·판정 시장 조사](research/한국_부동산_정보·판정_시장조사_2026-11.md)

2026년 11월 조사 기준, 이 시장의 기능 지도는 사실상 완성돼 있다.
**"AI로 매물 추천"은 이미 선점된 영역**이고, 이건 따라갈 수 없다.
선점된 것과 남은 것을 갈라 놓으면 이렇다.

| 축 | 이미 선점된 영역 | 남은 빈틈 |
|---|---|---|
| 탐색 | 직방 AI중개사·MCP, 네이버 AI탭, 다방 AI방찾기 | 여러 플랫폼을 관통하는 단일 조건 필터 |
| 자격 | 직방 청약진단 12개 유형, 호갱노노 청약 진단 | 공급 파이프라인 × 개인 조건 매칭 |
| 계약 | 직방 지킴진단, 다방 안심진단 | 세제 영향액이 붙은 총 실현 가능성 |
| 신뢰 | — | 매물 게시 누적량 vs 실제 재고(서울 상위 10대단지 전세 매물 3.6%) |
| 정책 | 국토부 공식 X·Threads | 지라시와 진짜를 가르는 진실성 판정 |
| 유통 | — | AI 검색 노출(GEO): 호갱노노 100 / 네이버 91 / 직방 85.8 |

그래서 진입점을 세 축으로 다시 잡는다.

1. **시장 전체를 관통하는 실현 가능성 판정.** 자기 매물 창고 안에서만 통하는 AI 추천을 넘어,
   청약 자격·소득·순자산·대출잔액·통근 제약을 넣고 여러 플랫폼의 공급·매물·공시를 관통한다.
   직방·호갱노노가 복제하지 못하는 유일한 데이터 축은 사용자 측 프로필이다.
2. **공급 파이프라인과 개인 조건의 결합.** SH·GH의 착공·준공 계획표는 추정치가 아니라 표라
   "3년 이내 입주"가 **조회**로 나온다. 3년은 사용자에게 가장 긴 구간이자
   경쟁자가 따라오기 가장 어려운 구간이다.
3. **정책의 진실성 판정.** 국토교통부는 2026년에 "부동산 대책 지라시" 유포를 네 차례 수사 의뢰했다.
   시장이 필요로 하는 것은 정책의 존재가 아니라 **적용 가능성과 진실성**이다.

타깃을 "주거 + 투자"로 넓히면 판정 축이 갈린다. 아파트 청약 룰은 투자에 통하지 않는다.
투자의 축은 **세제·수익성·계약가능성**인데 이 축은 이미 계산기 시장이 포화다.
남는 것은 계산이 아니라 **감시**다. 등록임대 세액감면 2028-12-31 일몰,
다주택 양도소득세 중과 유예 2026-05-09 종료 같은 일정 변화가 자동 감시 대상이 된다.

그래서 JihaMatch는 **매물 플랫폼이 아니다. 중개 플랫폼도 아니다.**

## 핵심 전략: 피하는 싸움

| | 포털형 (피해야 함) | JihaMatch (선택) |
|---|---|---|
| 데이터 | 매물 원문 크롤링·재게시 | 원문 미보관, **파생정보(점수·판정)**만 |
| 정체성 | 매물 중개·광고 | **의사결정 대행 에이전트** |
| 서로게시 | 자기 매물 노출 경쟁 | 중개사·플랫폼에 **딥링크 위임** |
| 수익 | 광고·중개 수수료 | 구독 + 중개사·금융사 리퍼럴 |
| 리스크 | DB권 침해, 매일 제소 가능 | 선제적 컴플라이언스 |

## 3가지 결합한 차별점

### 1. 조건 → 실현 가능성 계산기
"내 예산 5억인데 ?" 라는 질문이 아니라
**"내 청약·소득·자산·부채 조건 기준으로 이 집의 실제 인수 비용은 얼마이고, 대출은 몇 %까지 되는가"**

- 전 부담액: 매매가 + 취득세 + 중개보수 + 잔수리 + 이사 + 비품 + 대출금리(총부담액)
- 청약 자격: 국민주택기금 무주택요건 / 청약통장 / 소득 / 순자산 / 지역제한
- 금융: LTV·DSR·스트레스 DSR, 기금부채, 전세반환상품

### 2. 정책 매칭 엔진 (가장 큰 화이트스페이스)
공고가 뜨면 알려주는 게 아니라, **지금 나에게 적용 가능한가**를 판정해서 알려준다.

- LH·HUG·한국부동산원 공고/분양/임대 (전국 100% 공식 오픈API)
- 청약 자격 자동 판정 → "이 공고 나 자격 있다/없다"
- 제공: 세제·금융 지원 (취득세 감면, 생애최초, 신혼부부, 다자녀, 무주택주체...)
- 법령 변화 감시 → "이 법이 바뀌었습니다, 님에게 영향 N원"

### 3. 상태 변화 알림 (알림이 아니라 이벤트)
매물 알림은 이미 아무도 못 하는 노이즈다. 대신:

> **"내 상황이 바뀌었다"를 알린다.**

```
[매물] AGT 2동 802, 6억2천, 실거래 대비 -4.2%
        → "당신 조건 100% 충족. LTV 60% → 대출 3.7억. 3개월 내 12건 동급 거래 대비 적정가 하위 8%"
        ⏰ 선점형. 보유 예산 3.7억.

[공고] 해운대 e편한세상 4차 84㎡, 공급가 3억9천
        → "무주택 + 청약통장 24개월, 특별공급 조건 충족. 잔여 세대 확인. 마감 D-2"
        ⏰ D-2. 이건 놓치면 다음은 몇 개월 뒤.

[정책] 12월 기준금리 -0.25%p 하향
        → "당신 대출 실행일 1.8개월 당김. 이자 절감 약 63만 원/년"
```
